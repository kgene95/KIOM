# CMPE Manuscript

## 분석 유형
CMPE 원고 편집 자료입니다. 새로운 NP 분석 결과는 해당 GPT 또는 Direct 분석 폴더에서 관리합니다.

## Provenance
그림·표·보충자료에는 출처 프로젝트, GPT/Direct 유형, 실행 ID, 원본 경로와 file_id를 기록합니다.
drafts는 원고 초안, figures는 원고용 그림, tables는 표, references는 참고문헌, supplementary는 보충자료입니다.

## 데이터 혼합 금지
GPT/Direct 결과를 인용·비교할 때 출처를 구분하며 원자료·중간 결과를 합치지 않습니다.
다른 프로젝트 데이터와 혼합하지 않으며 프로젝트별 화합물·유전자 데이터를 00_shared에 저장하지 않습니다.
현재는 폴더만 초기화했고 원고·실제 분석 결과는 미등록 상태입니다.
