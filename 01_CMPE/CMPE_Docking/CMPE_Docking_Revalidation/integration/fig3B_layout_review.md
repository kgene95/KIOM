# Fig. 3B visual replacement — review layout

The original Fig. 3B is a composite panel: full-protein overview, boxed binding-site close-up, and a Discovery Studio 2D interaction map. The revalidated 4KIK panel should preserve the first two visual functions without carrying over unverified 3RZF interaction labels.

## Proposed panel composition

1. **Left:** full 4KIK chain-B cartoon in forest green with the neutral-vitexin rank-1 pose in cyan sticks. Use `fig3B_4KIK_overview_review.cxc`.
2. **Right:** enlarged view of the same pose, with residues within 5 Å in yellow sticks. Use `fig3B_4KIK_pocket_review.cxc`.
3. **Inset rule:** do not reproduce the historical Discovery Studio 2D interaction map. The new package has PLIP 3.0.1 seedwise interaction records, but the current visual draft uses a 3D pocket context rather than embedding a new 2D interaction diagram.

## Fixed scientific labels

- `Human IKKβ (4KIK chain B)`
- `Vitexin-4″-O-glucoside, neutral state`
- `AutoDock Vina 1.2.7; KSA redocking RMSD 0.3808 Å`

## Draft-only status

This layout is for composition review. Export a final manuscript panel only after the user accepts the overview, pocket zoom, colors, and labels.
