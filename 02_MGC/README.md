# MGC

## 분석 유형
- [01_NP_GPT](01_NP_GPT/README.md): 5개 화합물의 GPT 보조 NP 분석.
- [02_NP_Direct](02_NP_Direct/README.md): 연구자가 직접 수행한 멸가치 NP 분석.
- [03_Manuscript](03_Manuscript/README.md): 원고·그림·표·참고문헌·보충자료.

## Provenance와 데이터 혼합 금지
각 분석의 metadata에서 출처·조건·파일 계보를 독립적으로 기록합니다.
GPT와 Direct의 원자료·중간 결과를 혼합하지 않고, 다른 프로젝트 자료도 섞지 않습니다.
원고에서 비교·인용할 때 분석 유형·실행 ID·원본 경로를 유지합니다.
프로젝트별 화합물·유전자 데이터는 00_shared에 저장하지 않습니다.

현재 상태는 폴더와 템플릿 초기화입니다. 실제 데이터와 분석 결과는 아직 등록하지 않았습니다.
