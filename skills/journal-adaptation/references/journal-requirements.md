# Journal requirements extraction

Verify only requirements relevant to the selected article type.

Capture:
- article type and scope fit constraints that affect format;
- title rules and running title;
- abstract type and length;
- keywords;
- main-text length and section order;
- required headings/subheadings;
- nomenclature/abbreviation rules when explicit;
- reference style and citation format;
- figure count, file type, resolution, dimensions, color requirements, and legend rules;
- table rules;
- supplementary-material rules;
- graphical abstract, highlights, key points, lay summary, or similar items;
- ethics, funding, conflict, author contribution, data/code availability, trial registration, and AI disclosure requirements;
- cover letter requirements;
- required checklists or reporting statements;
- submission-system file separation requirements.

Record the official source and access date for requirements that may change. When official pages conflict, prefer the most specific page for the article type and flag unresolved conflicts.
