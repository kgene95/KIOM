# Submission completeness audit

Check, as applicable:
- ethics approval and identifier;
- informed consent/consent waiver for human research;
- animal welfare and euthanasia reporting;
- funding;
- conflicts of interest;
- author contributions;
- data availability;
- code availability when relevant;
- trial/registry information when relevant;
- acknowledgements;
- supplementary files and their in-text citations;
- figure/table/legend completeness;
- abbreviations and nomenclature consistency;
- reference list completeness and unresolved citations;
- AI-use disclosure only when required by the target journal or institution.

Do not apply target-journal formatting here. Target-journal rules belong to `journal-adaptation`.
