# Reporting guideline gate

Identify the study design, then apply the relevant current guideline using official sources when verification is needed.

Common mappings:
- animal in vivo research -> ARRIVE 2.0;
- randomized controlled clinical trial -> CONSORT;
- observational epidemiology -> STROBE;
- systematic review/meta-analysis -> PRISMA;
- diagnostic accuracy -> STARD;
- case report -> CARE;
- prediction model -> TRIPOD or current successor guidance where applicable;
- health economic evaluation -> CHEERS.

Audit what is reported, not what you assume occurred. Mark each required element as present, incomplete, absent from the manuscript, not applicable, or needs verification. Never insert unverified statements such as randomization or blinding merely to satisfy a checklist.
