# Provenance 기록 규칙

1. 자료 등록 전 해당 분석의 source_registry에 고유 source_id, 원본 파일명, 출처 URL/인용, DB 버전, 조회일, 생성 주체, 라이선스, SHA-256을 기록합니다. 미확정 값은 빈 값과 notes 설명으로 남깁니다.
2. analysis_metadata에 프로젝트·유형·실행 ID, 수행자, 도구/모델 버전, 매개변수, 프롬프트 또는 작업 기록 경로를 기록합니다.
3. file_manifest에는 고유 file_id, 저장소 상대 경로, 역할(raw/processed/result 등), source_ids, parent_file_ids, 생성 시각·주체·해시·검토 상태를 기록합니다. 복수 ID는 세미콜론으로 구분합니다.
4. branch_registry는 **분석 분기** 레지스트리입니다. Git 브랜치와 다르며 git_ref는 관련 커밋·브랜치를 선택 기록합니다. 초기에는 헤더만 두고 실제 분석 분기가 시작될 때 행을 추가합니다.
5. GPT 결과는 모델·프롬프트·응답·실행 시각을 보존하고 연구자 검토 상태를 명시합니다. 근거가 확인되지 않은 값은 확정하지 않습니다.
6. Direct 결과는 연구자·도구·버전·입력·설정·실행 기록으로 추적합니다. 다른 분석 유형의 결과를 Direct 원자료로 재표시하지 않습니다.
7. 결과 및 원고는 부모 file_id와 분석 유형까지 연결합니다. 보관 시에도 계보를 보존합니다.
8. 날짜는 YYYY-MM-DD, 시각은 시간대가 포함된 ISO 8601을 사용합니다. 표준 시간대는 Asia/Seoul입니다.
9. 초기화된 빈 CSV와 null 값은 미등록 상태입니다. 실제 분석·검증 완료를 뜻하지 않습니다.

source_id, file_id, branch_id의 고유 범위는 각 분석 폴더입니다. 분석 밖에서 인용할 때 프로젝트·유형·경로를 함께 명시합니다.
