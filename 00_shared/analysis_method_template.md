# 분석 방법 기록 템플릿

공통 방법 서식입니다. 프로젝트별 화합물·유전자 값이나 결과를 이 파일에 입력하지 마십시오.
복사본을 해당 분석의 `reports/`에 저장하고 실제 조건을 작성합니다.

- 프로젝트 / 분석 유형 / 실행 ID:
- 연구 목적 / 대상 / 포함·제외 기준:
- 입력 source_id / file_id / SHA-256:
- 데이터베이스 이름 / 버전 / 조회일 / URL / 라이선스:
- 종 / 식별자 체계 / 정규화·중복 제거 방법:
- 표적 선정 / 질환 유전자 선정 기준:
- PPI 데이터베이스 / 버전 / 종 / 신뢰도 임계값:
- enrichment 도구 / 버전 / background / 다중검정 / 유의수준:
- GPT 사용 시 모델·버전 / 실행 시각 / 프롬프트 경로 / 응답 경로 / 검증 절차:
- Direct 분석 시 수행 연구자 / 소프트웨어·버전 / 스크립트 또는 작업 기록:
- 각 단계의 부모 파일 / 매개변수 / 출력 파일:
- 결과 검토자 / 검토일 / 한계:
- 재실행 방법 / 변경 이력:

미확정 값은 미확정으로 표시합니다. GPT 출력은 근거 검증 전 확정 데이터로 취급하지 않습니다.
